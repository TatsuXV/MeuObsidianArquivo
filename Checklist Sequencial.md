### Bloco 15 — Testes
- [ ] **[ESSENCIAL]** JUnit (Unit Testing) — padrão do ecossistema Java/Spring
- [ ] **[OPCIONAL]** TestNG — resolve o mesmo problema que JUnit; não estude os dois, pule se já for de JUnit
- [ ] **[ESSENCIAL]** Mockito (Mocking) — anda junto com JUnit em praticamente todo projeto Spring
- [ ] **[BOM SABER]** REST Assured (Integration Testing) — ótimo pra portfólio, mostra que você testa API de verdade
- [ ] **[OPCIONAL]** JMeter — isso é ferramenta de teste de *performance/carga*, não de integração; não é prioridade pra júnior
- [ ] **[OPCIONAL]** Cucumber-JVM (Behavior Testing) — raro ser exigido em vaga júnior, deixe pra depois
